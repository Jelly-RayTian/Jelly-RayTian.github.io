## Overview

In high school I experimented with iOS device customization: using the Dopamine jailbreak, setting up TrollStore on an iPad mini 6, and working with third-party software sources. I used tools written by other people. I did not develop a jailbreak, an exploit or either of these tools. These were personal experiments, not professional work. Some implementation details are no longer documented.

## Technical Background

- **Jailbreaking** removes some of iOS's restrictions so that apps and tweaks can change how the system behaves.
- **Dopamine**, by opa334, is described by its author as a semi-untethered jailbreak for a range of iOS 15 to 26 versions.
- **TrollStore**, also by opa334, is described by its author as an app that can install IPA files permanently, and it only works on specific iOS versions.
- **Software sources** are package repositories that a jailbroken device can pull apps and tweaks from.

## My Experiment

- Used the Dopamine jailbreak.
- Set up TrollStore on an iPad mini 6.
- Worked with third-party software sources (repositories).
- Hands-on experimentation with iOS jailbreaking and device customization in general.

## Result

I got these tools running and used them. iOS versions, which device ran Dopamine, and the exact steps were not recorded, so they are not stated here.

## What I Learned

- That which tool works depends on the exact device and iOS version, so the project's own supported-version notes are the first thing to read.
- How apps are installed and signed on iOS differs from other platforms, and third-party sources need the same care as any outside code.
